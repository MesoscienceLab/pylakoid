# Checker Helpers

`pylakoid.structure.checker_helpers` contains functions which help prepare checkers found in
`pylakoid.structure.checker`.

## Public API

The public API of `pylakoid.structure.checker_helpers` consists of the following functions.

::: pylakoid.structure.checker_helpers.get_atomic_hull2d
    options:
      heading_level: 3

::: pylakoid.structure.checker_helpers.prepare_boundary
    options:
      heading_level: 3

::: pylakoid.structure.checker_helpers.prepare_atomic_hull_inside_polygon_checker
    options:
      heading_level: 3
